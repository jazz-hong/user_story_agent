# User Story Agent

Creator
- Jazz Hong

Intro
- Lightweight web tool that converts meeting notes or raw requirements into well-structured Agile user stories using an AI backend.

Current features
- File input: .docx, .pdf, .html, .md, .txt
- Drag & drop upload and paste input
- Automatic text extraction and story generation
- Story formatting with acceptance criteria and clarification flags
- Local API key storage and usage tracking
